# CLAUDE.md

**Read [docs/ONBOARDING.md](docs/ONBOARDING.md) first.** It is the orientation map for this
repository — what it is, how the layers fit together, how to run things on this machine, the
invariants a change must not break, and the current state of the working tree.

Three things worth knowing before the first command:

- **Authority order.** `docs/DECISIONS.md` (D1–D73) wins over the README, which wins over
  `docs/ARCHITECTURE.md` (a historical plan, partly superseded). Search DECISIONS before
  proposing a redesign — the alternative was probably already rejected, with reasons.
- **Running anything.** `python` on PATH is the Microsoft Store stub. Use an activated conda
  env; invoking `python.exe` by full path without activation crashes inside LAPACK
  (`Windows fatal exception: code 0xc06d007f`). Full suite:
  `& "C:\Users\paljo\AppData\Local\miniforge-pypy3\Scripts\conda.exe" run -n themis-assess-forecast python -m pytest`
- **Dependencies.** `pyproject.toml` is the single source of truth; `requirements*.txt` and
  `environment.yml` are generated by `python tools/sync_requirements.py` and a test fails
  when they are stale. The core must never import an optional extra at module level.
